# Solved Exercises Vue

Colección de retos de programación resueltos con **Vue 3**, basada en el repositorio de ejercicios interactivos de [DevTalles](https://github.com/DevTalles-corp/devtalles-interactive-web-development-excercises). El propósito de este proyecto es puramente educativo: aprender y practicar conceptos de programación front-end utilizando Vue 3 y su ecosistema moderno.

Cada reto se resuelve dentro de su propio componente o directorio, y en algunos casos puede haber más de una solución propuesta para el mismo ejercicio, con el fin de explorar distintos enfoques y patrones de Vue.

## 🛠️ Tecnologías

- **HTML5**
- **TypeScript**
- **Vue 3** (Composition API + `<script setup>`)
- **Tailwind CSS v4**
- **Vite**

## 📋 Requisitos previos

- [Node.js](https://nodejs.org/) v18 o superior
- [npm](https://www.npmjs.com/) v9 o superior

## 🚀 Guía de inicio rápido

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Ibrainm/solved-excercises-vue.git
   cd solved-excercises-vue
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Abre tu navegador en `http://localhost:5173` y explora los ejercicios.
